# Analysis examples

These examples use deterministic inputs and state what the transformation changes.
All figures are generated by
[`scripts/docs_gallery.py`](https://github.com/El3ssar/hilbertplot/blob/main/scripts/docs_gallery.py).
The Fourier and granularity datasets come directly from `examples/readme_figures.py`.

## Thue–Morse: spatial spectral structure

**Input:** 1,048,576 binary terms, arranged on a 1024-square Hilbert grid.
**Operation:** mean subtraction, separable Hann window, centred 2-D FFT magnitude,
then `log1p` display scaling.

```{raw} html
<div class="plot-pair">
<figure><img src="_static/generated/fourier-input.png" alt="One million Thue-Morse terms on the Hilbert grid"></figure>
<figure><img src="_static/generated/fourier-spectrum.png" alt="Centred 2-D Fourier magnitude with Hann window"></figure>
</div>
```

The spectral map displays repeated structure across scales. The input is aperiodic;
its structure should not be described as a single hidden period. Changing the curve
changes this spatial spectrum. [Reproduction and interpretation](guides/fourier.md).

## Equal-density runs: separating periodic regions

**Input:** seeded interleaving of period-4 and period-6 binary runs with equal density.
**Operation:** repeat the mean of each consecutive four-sample block.

```{raw} html
<div class="plot-pair">
<figure><img src="_static/generated/granularity-input.png" alt="Interleaved periodic runs without averaging"></figure>
<figure><img src="_static/generated/granularity-result.png" alt="The same runs with granularity four"></figure>
</div>
```

Period-4 runs become uniform while period-6 runs retain block variation.
The regions are distinguished by response to averaging, not by different input means.
[Dataset construction and block-length dependence](guides/granularity.md).

## Curve locality: comparing geometric fields

**Input:** four curve constructions at the same resolution.
**Operation:** average visit-index distance to up-to-eight spatial neighbours.

![Comparable locality fields with shared logarithmic color limits](_static/generated/locality.png)

These plots do not use measurement values. The shared logarithmic scale makes both
small and large distances visible. [Field definition and numeric output](guides/locality.md).

## RGB arrays: exact reconstruction and permutation

**Input:** a synthetic RGB image with known horizontal, vertical and diagonal variation.
**Operation:** read its pixels along curve 0, then write the sequence using curve 0 or 12.

![RGB input, reconstruction with the same curve and permutation with another](_static/generated/rgb_roundtrip.png)

The same curve recovers every channel value exactly. A different curve changes spatial
placement while retaining the pixels. [Conversion guarantees](guides/conversion.md).

## Color normalization: positive values across several scales

**Input:** `exp(3*sin(i/37))`, ranging from approximately 0.05 to 20.09.
**Operation:** linear or logarithmic color normalization of the same mapped values.

![The same positive array with linear and logarithmic color normalization](_static/generated/normalization.png)

Logarithmic color normalization changes visibility across value ranges; it does not
transform the stored array or calculate a Fourier spectrum.
[Plotting options](quickstart.md#color-normalization).
